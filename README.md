# BakaPlus jsou nyní Student+!

**Moderní neoficiální Android klient** pro školní systém **Bakaláři**, navržený s důrazem na **rychlost**, čistý **design** a **funkce**, které považuji za samozřejmost.

---
##  Hlavní funkce

* **Notifikace:** Integrované notifikace přes **FCM** v oddělených **notifikačních kanálech** na známky, úkoly, komens a další.
* **Moderní UI:** Vzhled je zaměřen na čistě **černou barvu**, aby vynikl na **AMOLED** displejích a **šetřil baterii**.
* **Účty:** jednoduchý přepínač účtů s nastavením **primárního účtu** a **automatického přihlášení**
* **Průměr:** Průměr se zobrazuje i u škol, které ho oficiálně nepodporují. Ke známkám se dá nastavit **vlastní váha**.
* **Předvídač:** Opět funkce, která se zobrazuje **na všech školách** a je lépe integrována do rozhraní, než v oficiální aplikaci.
* **Uzamčení aplikace:** Možnost uzamknout aplikaci otiskem prstu pro ochranu soukromí.
* **Výchozí obrazovka:** Možnost si zvolit, která stránka se zobrazí při otevření jako první.
* **Widget:** Zobrazení rozvrhu ještě před otevřením aplikace.
